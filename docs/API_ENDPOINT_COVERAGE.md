# Cakupan endpoint API

`API_ENDPOINT_COVERAGE.csv` adalah daftar kerja dari **Spesifikasi API digaji.id — REST + WebSocket.md**. Jalankan `python scripts/api-coverage.py` setelah menambah operasi OpenAPI. Status `active` berarti pasangan method dan path yang sama persis telah dicatat di OpenAPI aktif; `planned` berarti belum. Alias lama dan endpoint tambahan dihitung terpisah, sehingga angka ini adalah alat pelacak, bukan klaim bahwa seluruh alur bisnis telah selesai.

Per 8 November 2026: spesifikasi menghasilkan **506 operasi** setelah metode gabungan dan lima master organisasi diuraikan. **194** pasangan method/path cocok dengan OpenAPI aktif, **312** masih direncanakan. OpenAPI aktif berisi **247 operasi**, termasuk alias kompatibilitas dan tambahan pola jadwal yang belum tertulis dalam tabel spesifikasi.

Irisan terbaru menambah tiga operasi periode payroll dan satu pratinjau cicilan kasbon yang jatuh tempo. Pratinjau hanya membaca cicilan pending, belum membuat run atau mengurangi outstanding; cicilan waived/settled tidak muncul. Operasi kasbon sebelumnya mencakup kebijakan plafon dan tenor per tenant, simulasi, pengajuan, approval, pencairan idempotent, pembebasan cicilan, dan pelunasan penuh di luar payroll. Potongan cicilan melalui payroll dan finalisasi payroll belum aktif. File kuitansi reimbursement masih memakai penyimpanan lokal staging tanpa antivirus atau penyimpanan produksi. Penulisan presensi, job, dan modul lain dilanjutkan menurut `BACKEND_API_IMPLEMENTATION_PLAN.md`. Rute yang belum memiliki perilaku server tidak dimasukkan ke OpenAPI aktif.
