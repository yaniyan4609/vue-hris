# Cakupan endpoint API

`API_ENDPOINT_COVERAGE.csv` adalah daftar kerja dari **Spesifikasi API digaji.id — REST + WebSocket.md**. Jalankan `python scripts/api-coverage.py` setelah menambah operasi OpenAPI. Status `active` berarti pasangan method dan path yang sama persis telah dicatat di OpenAPI aktif; `planned` berarti belum. Alias lama dan endpoint tambahan dihitung terpisah, sehingga angka ini adalah alat pelacak, bukan klaim bahwa seluruh alur bisnis telah selesai.

Per 8 November 2026: spesifikasi menghasilkan **506 operasi** setelah metode gabungan dan lima master organisasi diuraikan. **201** pasangan method/path cocok dengan OpenAPI aktif, **305** masih direncanakan. OpenAPI aktif berisi **255 operasi**, termasuk alias kompatibilitas dan tambahan pola jadwal yang belum tertulis dalam tabel spesifikasi.

Irisan terbaru menambah CRUD komponen gaji nominal `fixed` dan riwayat penetapan per karyawan. Penetapan memerlukan scope dan izin sensitif, reauth, tanggal berlaku, serta versi optimistik; nominal disamarkan bagi pembaca tanpa izin sensitif. Simulasi cicilan kasbon dengan `available_net` masukan Finance Payroll menunda cicilan utuh bila tidak cukup dan tidak mengubah data. Tiga operasi periode payroll dan pratinjau cicilan jatuh tempo juga aktif. Kalkulasi gaji/pajak/BPJS, posting cicilan, dan finalisasi payroll belum aktif. File kuitansi reimbursement masih memakai penyimpanan lokal staging tanpa antivirus atau penyimpanan produksi. Penulisan presensi, job, dan modul lain dilanjutkan menurut `BACKEND_API_IMPLEMENTATION_PLAN.md`. Rute yang belum memiliki perilaku server tidak dimasukkan ke OpenAPI aktif.
