# Cakupan endpoint API

`API_ENDPOINT_COVERAGE.csv` adalah daftar kerja dari **Spesifikasi API digaji.id — REST + WebSocket.md**. Jalankan `python scripts/api-coverage.py` setelah menambah operasi OpenAPI. Status `active` berarti pasangan method dan path yang sama persis telah dicatat di OpenAPI aktif; `planned` berarti belum. Alias lama dan endpoint tambahan dihitung terpisah, sehingga angka ini adalah alat pelacak, bukan klaim bahwa seluruh alur bisnis telah selesai.

Per 8 November 2026: spesifikasi menghasilkan **506 operasi** setelah metode gabungan dan lima master organisasi diuraikan. **201** pasangan method/path cocok dengan OpenAPI aktif, **305** masih direncanakan. OpenAPI aktif berisi **256 operasi**, termasuk alias kompatibilitas dan tambahan pola jadwal yang belum tertulis dalam tabel spesifikasi.

Irisan terbaru menambah pratinjau kesiapan prorata berdasarkan hari kerja pada roster terbit. Roster seluruh tanggal periode harus lengkap agar nominal boleh dihitung pada tahap berikutnya. CRUD komponen gaji `fixed` dan riwayat penetapan per karyawan juga aktif, dengan izin sensitif, reauth, tanggal berlaku, dan versi optimistik. Simulasi cicilan kasbon dengan `available_net` masukan Finance Payroll menunda cicilan utuh bila tidak cukup dan tidak mengubah data. Kalkulasi gaji/pajak/BPJS, posting cicilan, dan finalisasi payroll belum aktif. File kuitansi reimbursement masih memakai penyimpanan lokal staging tanpa antivirus atau penyimpanan produksi. Penulisan presensi, job, dan modul lain dilanjutkan menurut `BACKEND_API_IMPLEMENTATION_PLAN.md`. Rute yang belum memiliki perilaku server tidak dimasukkan ke OpenAPI aktif.
