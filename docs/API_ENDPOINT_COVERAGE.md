# Cakupan endpoint API

`API_ENDPOINT_COVERAGE.csv` adalah daftar kerja dari **Spesifikasi API digaji.id — REST + WebSocket.md**. Jalankan `python scripts/api-coverage.py` setelah menambah operasi OpenAPI. Status `active` berarti pasangan method dan path yang sama persis telah dicatat di OpenAPI aktif; `planned` berarti belum. Alias lama dan endpoint tambahan dihitung terpisah, sehingga angka ini adalah alat pelacak, bukan klaim bahwa seluruh alur bisnis telah selesai.

Per 8 November 2026: spesifikasi menghasilkan **506 operasi** setelah metode gabungan dan lima master organisasi diuraikan. **191** pasangan method/path cocok dengan OpenAPI aktif, **315** masih direncanakan. OpenAPI aktif berisi **243 operasi**, termasuk alias kompatibilitas dan tambahan pola jadwal yang belum tertulis dalam tabel spesifikasi.

Irisan terbaru menambah 12 operasi kasbon: kebijakan plafon dan tenor per tenant, simulasi, pengajuan, daftar/detail sesuai scope, approval, pencairan idempotent, pembebasan cicilan, dan pelunasan penuh di luar payroll. Cicilan pertama jatuh pada bulan setelah pencairan; total outstanding menjadi dasar plafon bersama pengajuan yang masih menunggu keputusan. Potongan cicilan melalui payroll belum aktif. File kuitansi reimbursement masih memakai penyimpanan lokal staging tanpa antivirus atau penyimpanan produksi. Penulisan presensi, payroll, job, dan modul lain dilanjutkan menurut `BACKEND_API_IMPLEMENTATION_PLAN.md`. Rute yang belum memiliki perilaku server tidak dimasukkan ke OpenAPI aktif.
