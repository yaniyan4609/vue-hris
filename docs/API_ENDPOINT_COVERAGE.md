# Cakupan endpoint API

`API_ENDPOINT_COVERAGE.csv` adalah daftar kerja dari **Spesifikasi API digaji.id — REST + WebSocket.md**. Jalankan `python scripts/api-coverage.py` setelah menambah operasi OpenAPI. Status `active` berarti pasangan method dan path yang sama persis telah dicatat di OpenAPI aktif; `planned` berarti belum. Alias lama dan endpoint tambahan dihitung terpisah, sehingga angka ini adalah alat pelacak, bukan klaim bahwa seluruh alur bisnis telah selesai.

Per 8 November 2026: spesifikasi menghasilkan **506 operasi** setelah metode gabungan dan lima master organisasi diuraikan. **203** pasangan method/path cocok dengan OpenAPI aktif, **303** masih direncanakan. OpenAPI aktif berisi **260 operasi**, termasuk alias kompatibilitas dan tambahan pola jadwal yang belum tertulis dalam tabel spesifikasi.

Irisan terbaru menambah baca dan publikasi aturan PPh 21 serta BPJS **per tenant** dengan tanggal berlaku, sumber aturan, reauth, audit, dan pencegahan perubahan yang menyentuh payroll final. PPh 21 memakai editor data terstruktur untuk PTKP, TER bulanan, dan rentang tahunan; tarif tidak diisi otomatis. Pratinjau prorata, CRUD komponen `fixed`, dan simulasi cicilan kasbon juga aktif. **Mesin hitung pajak/BPJS, posting cicilan, dan finalisasi payroll belum aktif.** File kuitansi reimbursement masih memakai penyimpanan lokal staging tanpa antivirus atau penyimpanan produksi. Penulisan presensi, job, dan modul lain dilanjutkan menurut `BACKEND_API_IMPLEMENTATION_PLAN.md`. Rute yang belum memiliki perilaku server tidak dimasukkan ke OpenAPI aktif.
